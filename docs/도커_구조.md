# Docker 구조 - 현재 서버 확정안

```text
기존 MOVEAI Caddy (:80/:443)
        |
        | yellow.it.kr -> host.docker.internal:9000
        v
Dahum Caddy (host :9000 -> container :80)
        |
        v
Dahum Spring Boot :8080
  |- React static files
  |- REST / OAuth
  |- FastAPI :8000 (internal)
  `- MariaDB :3306 (internal)
```

## 컨테이너

- `dahum-caddy`: Dahum의 host 9000 단일 진입점
- `backend`: React 정적파일 + Spring API/OAuth를 함께 제공
- `ai`: FastAPI, 외부 publish 금지
- `mariadb`: MariaDB, 외부 publish 금지

`frontend`는 production runtime container가 아니다. `backend/Dockerfile`의 build stage에서 React를 빌드해 Spring JAR에 넣는다. `frontend/Dockerfile`은 독립 프론트 build 검증용이다.

## 포트

| 포트 | 역할 |
|---|---|
| 22 | SSH / GitHub Actions |
| 80/443 | 기존 MOVEAI Caddy가 계속 점유 |
| 9000 | Dahum Caddy host port |
| 8080 | Spring container internal |
| 8000 | FastAPI internal |
| 3306 | MariaDB internal |

## 금지

- Dahum compose에서 `80:80`, `443:443` 추가 금지
- React용 별도 9001 production port 추가 금지
- DB/AI host publish 금지
- secret을 image에 COPY 금지
